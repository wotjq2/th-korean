# 크롬 웹스토어에 올리기 — 통합 번역

## 1. 올릴 파일 만들기
```
node extension/build.js --store
```
→ `extension/store/통합번역-<판>.zip` (개발용 고정 id 열쇠 `key` 를 뺀 판 — 스토어가 거부한다).
사진 글자 읽기 엔진(Tesseract)은 zip 안에 들어 있다(웹스토어는 밖에서 받은 코드를 못 돌리게 한다).

## 2. 개발자 대시보드에 올린 뒤 — 한 번만
1. 스토어가 준 **확장 id**(영어 소문자 32자)를 저장소의 `config.json` → `"helper": { "extensionIds": ["<그 id>"] }` 에 적어 GitHub 에 올린다.
2. 번역 도우미는 6시간 안에 그 id 를 받아 크롬에 다시 알린다(트레이 메뉴 '업데이트 확인' 으로 바로). **도우미 코드는 고치지 않는다.**

## 3. 올린 뒤에 바꾸는 법 — 무엇을 어디서
| 바꿀 것 | 고칠 곳 | 웹스토어 심사 |
|---|---|---|
| 태국어 단어 | th-korean-glossary 저장소 `glossary.txt` | 필요 없음 |
| 언어 더하기·이름·번역 코드, 언어별 용어집 | `config.json` 의 `languages` (+ th-korean-glossary 에 `glossary-xx.txt`) | 필요 없음 |
| 구글 번역 주소 차례(한쪽이 막혔을 때) | `config.json` 의 `translate.order` | 필요 없음 |
| 유튜브 화면이 바뀌어 자막·단추가 안 붙을 때 | `config.json` 의 `youtube` | 필요 없음 |
| 쇼핑몰 검색창이 바뀌었을 때, 쇼핑몰 더하기 | `config.json` 의 `shops` | 필요 없음 |
| 영상 자막 크기·자리·길이, '한국어 자막' 단추 자리 | `config.json` 의 `video`, `chip` | 필요 없음 |
| 사진 글자 읽기 언어 | `config.json` 의 `ocr.lang` | 필요 없음 |
| 새 기능, 버그 고치기(코드) | `th-korean.user.js`, `extension/` | **필요** — `@version` 을 올리고 1번부터 |

`config.json` 은 칸마다 꼴을 맞춰 보고 틀린 칸만 버린다(기본값으로). 저장 전에 JSON 문법(쉼표·따옴표)만 확인한다.

## 4. 스토어 등록 화면에 적을 것

**이름**: 통합 번역

**짧은 설명**(132자 이내):
외국어 사이트·메신저·영상을 한국어로 — 태국 쇼핑몰 한국어 검색, 페이스북 메신저, 유튜브·틱톡·페이스북 영상 한국어 자막, 입력칸 한국어→외국어

**자세한 설명**:
- 태국 쇼핑몰(라자다·쇼피): 한국어로 검색하면 태국어로 바꿔 검색, 상품 화면·사진 속 태국어를 한국어로
- 페이스북 메신저: 태국어 메시지 아래 한국어, 한국어로 쓰면 태국어로 보내기
- 영상: 유튜브·쇼츠는 외국어 영상이면 한국어 자막이 저절로. 틱톡·페이스북 릴스처럼 자막이 없는 영상은 크롬 '실시간 자막'과 번역 도우미(윈도우 프로그램, 선택)로 영상 위에 한국어 자막
- 어느 사이트든 입력칸의 한국어를 태국어·영어·중국어 등으로 바꾸기
- 번역은 공개 용어집을 먼저 보고, 없으면 Google 번역

**하나의 목적(single purpose)**: 사용자가 보는 외국어 웹 콘텐츠(글·사진·영상)를 한국어로 옮기고, 사용자가 쓴 한국어를 외국어로 옮긴다.

**권한마다 까닭**:
- `storage`, `unlimitedStorage`: 설정·용어집 사본(수 MB)·번역해 둔 결과를 이 브라우저에 보관
- `nativeMessaging`: 사용자가 설치한 '번역 도우미'(LINE·화면 번역, 크롬 실시간 자막 한국어)를 켜고 끄기
- `downloads`: 번역 도우미가 없을 때 설치 파일 받기(사용자가 누를 때만)
- 모든 사이트에서 도는 스크립트(`http://*/*`, `https://*/*`): 어느 사이트든 입력칸의 한국어를 외국어로, 영상 위 한국어 자막, 외국어 페이지 감지
- 접속 주소(host permissions): translate.googleapis.com(번역), api.github.com·raw.githubusercontent.com(용어집·원격 설정), api.groq.com·integrate.api.nvidia.com·vision.googleapis.com(사용자가 키를 넣은 때만), lazcdn.com·slatic.net·susercontent.com(쇼핑몰 사진 글자 읽기 — 사진을 받아야 읽는다), 127.0.0.1(이 PC 의 번역 도우미)

**원격 코드**: 쓰지 않음. `config.json`·용어집은 값(글자·숫자)만이며 코드로 실행하지 않는다.

**데이터 사용 공개**: 웹사이트 콘텐츠(번역할 글)를 번역 서비스로 보냄 — 기능 제공 목적만, 팔지 않음, 다른 용도로 쓰지 않음.

**개인정보 처리방침 주소**: https://github.com/wotjq2/th-korean/blob/main/PRIVACY.md

**스크린샷**(1280×800 또는 640×400): 라자다 한국어 검색, 메신저, 유튜브 쇼츠 한국어 자막, 틱톡 한국어 자막, 입력칸 언어 바꾸기
