# 통합 번역 (크롬 확장)

Tampermonkey 없이 번역 스크립트(`th-korean.user.js`)를 그대로 돌리는 우리 확장.
스크립트는 하나뿐이고, 이 폴더는 그것을 확장 꼴로 감싸기만 한다(LINE 번역 도우미도 같은 스크립트를 쓴다).

## 만들기
```
node extension/build.js
```
→ `extension/dist/` (스크립트를 고칠 때마다 다시 만든다. 버전은 스크립트 `@version` 을 따른다)

## 이 PC 크롬에 넣기 (압축해제 로드)
1. 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
2. **[압축해제된 확장 프로그램 로드]** → `E:\Production program\web translator\extension\dist` 선택
3. 다시 만든 뒤에는 카드의 **↻(새로고침)** 을 누르고, 열린 페이지도 새로 고친다
- Tampermonkey 의 '태국 사이트 한국어' 는 꺼 둔다(둘 다 켜면 번역이 두 번 붙는다)

## Tampermonkey 설정 옮기기 (한 번)
API 키·GitHub 토큰·메신저 대화방 설정·보낸 말 기록은 Tampermonkey 안에만 있다.
1. Tampermonkey 를 잠깐 켜고, 대시보드에서 '태국 사이트 한국어' 스크립트만 끈다
2. 설정 → 일반 → **구성 모드: 고급** → 스크립트를 열어 **저장소** 탭 내용을 전부 복사
3. 도구 막대 '한' 아이콘(통합 번역) → **설정 옮기기** → 붙여 넣기 → **[가져오기]**
4. Tampermonkey 는 다시 꺼도 된다

## 파일
| 파일 | 하는 일 |
|---|---|
| `src/gm.js` | 몽키 흉내 — GM_getValue·setValue(확장 저장소), GM_xmlhttpRequest(background 로 대신 보냄), GM_addStyle, GM_registerMenuCommand(도구 막대 메뉴) |
| `src/background.js` | 다른 사이트 주소 요청을 확장 권한으로 보냄 (구글 번역·GitHub·AI·사진 서버) |
| `src/popup.*` | 도구 막대 단추 — 지금 탭의 번역 메뉴, 설정 옮기기·내보내기 |
| `build.js` | 위 + 스크립트 → `dist/` (manifest 의 버전·접속 주소는 스크립트 머리말에서) |
| `vendor/tesseract.min.js` | 스크립트 `@require` 를 받아 sha256 을 맞춘 사본 |
| `icons/` | `make-icons.ps1` 로 그린 '한' 아이콘 |

## 크롬 웹스토어에 올리기 전에 할 일
- 사진 글자 인식(Tesseract)의 워커·엔진을 지금은 jsdelivr 에서 받아 실행한다. 스토어는 바깥 코드를
  실행하는 것을 금지하므로, `worker.min.js`·`tesseract-core` 를 확장 안에 넣고 거기서 읽게 바꿔야 한다.
  (태국어 자료·단어 빈도표는 데이터라 바깥에서 받아도 된다)
- 접속 권한이 모든 사이트(`http://*/*`)라 심사가 길다 — 기본 사이트만 두고 나머지는 사용자가 허락하게 줄일지 정한다.
- 개인정보 처리방침 페이지(GitHub)와 스크린샷 1장.
